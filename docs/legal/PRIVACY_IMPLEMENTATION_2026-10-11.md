# 개인정보 처리방침 초안 및 실제 적용 과제

문서: `web/studio/app/src/content/privacy-ko.txt` (`AUD-PRIVACY 1.0-draft`).
공개 라우트: `/privacy`, `/terms/privacy`는 `/privacy`로 이동.
가입 화면·메뉴·권리자 서명 화면에서 연결한다. 검토본 상태를 본문과 화면에 표시한다.

## 저장소에서 확인한 처리 근거

| 영역 | 확인한 소스와 내용 |
|---|---|
| 계정 | `auth.rs`: 이메일·비밀번호 해시·사용자 식별자·로그인 세션. `config.rs`: 기본 세션 43,200초(12시간) |
| 프로필·계좌·문의 | `0039_studio_portal.sql`: 프로필, 지급계좌 암호문, 정산 신청, 문서·서명, 문의·알림 |
| 본인확인·납세 | `account.rs`, `0083_account_identity.sql`: 실명·생년월일·CI 해시·기관 거래와 해외 납세정보·암호화 TIN |
| 문자·계정복구 | `password_reset.rs`, `sms.rs`: 전화번호 해시·뒷자리, 인증번호·재설정 토큰 해시. 운영용 문자업체는 미설정 상태에서 거절 |
| 권리자 서명 | `signing.rs`, `0071_rights_signing_requests.sql`: 성명·생년월일·CI/IP 해시·User-Agent·서명 이미지·동의 기록. 실제 본인인증 업체 미설정 시 거절 |
| 브라우저 저장 | `lib/storage.ts`, 프로필·입력 저장 흐름: 로컬 저장값. 전체 삭제가 모든 로그아웃 경로에서 보장된다고 표현하지 않음 |
| 접근기록·임시기록 | `0073_privacy_controls.sql`: 담당자 접근기록 기본 2년. `privacy_maintenance.rs`: 만료·철회 세션과 인증 제한 기록은 24시간 경과 후 정리 대상. 운영자 실행이 필요하며 자동 실행 완료를 주장하지 않음 |
| 설문 | `web/survey/src/worker.js`: 설문·베타 연락처·동의, 제출 12개월 초과 기록 삭제용 scheduled 함수. 스케줄·실행상태는 운영에서 확인 필요 |
| 접속 중계 | `web/shared/transport.js`, `web/studio/worker.js`: Cloudflare 기반 요청 전달에서 IP·User-Agent를 필요한 경로로 전달. 실제 계약 법인·국가·저장·지원 접근은 코드만으로 확정하지 않음 |

가입 시 계정 생성·서비스 제공에 필요한 처리는 계약 체결·이행 근거로 안내하고, 처리방침 자체를 포괄적으로 필수 동의받는 체크박스를 제거했다. 서비스 이용약관 동의는 유지했다. 선택 기능의 별도 수집·이용·제공·국외 이전 동의 및 아동 동의의 실제 구현은 이 변경으로 완료되지 않는다.

권리자 서명에 있던 CI/IP의 ‘암호화된 값’ 표현을 실제 해시 처리에 맞게 정정했다. 기존 권리서명 동의는 유지하며, 서명 전 별도 동의와 제공 안내의 충족 여부는 실제 연동 때 확인한다.

## 정식 시행 전에 채워야 하는 사항

1. 실제 개인정보처리자, 보호책임자 또는 고충처리 부서, 회원·비회원·탈퇴자 모두 이용할 수 있는 이메일·전화·주소, 시행일.
2. 수탁자의 실제 계약 법인명·업무·재수탁자. 본인인증·문자·은행·저장·AI 업체의 지원 코드와 체결 계약을 구분한다.
3. 제3자 제공 대상별 이름·목적·항목·기간·법적 근거 및 필요한 별도 동의.
4. 국외 이전별 수령자·연락처·실제 국가·항목·시기·방법·목적·기간·법적 근거·거부절차·효과. 국내 리전과 해외 지원 접근을 함께 조사한다.
5. 미완료 인증·SMS 도전 기록·보안 로그의 실제 파기 기간과 실행주기, 백업 최대 잔존기간, 계정·권리·정산 자료별 법정 보존 분류 및 파기 절차.
6. 적용되는 소비자 거래는 계약·결제 5년, 불만·분쟁 3년, 표시·광고 6개월. 세무 장부는 원칙 5년·해당 역외거래 7년 등 법정 특례, 상법의 중요서류 10년·전표 5년을 해당 기록에만 적용한다. 계정 전체를 자동으로 최장기간 보관하지 않는다.
7. 탈퇴·동의 철회·정보주체 요청·만 14세 미만 아동 동의 확인 및 비회원 권리행사 절차. 일반 회원가입에 방침 링크가 있다고 아동 동의가 해결되는 것은 아니다.
8. 완전 자동 결정의 적용 대상, 기준·절차·입력·결과·인적 재검토 연락경로. 외부 AI의 보관·학습 제한과 국외 이전 검토.
9. 개인정보 동의 원장의 문서 ID·버전·해시·시각·고지문 사본, 이전 방침 제공 및 실제 파기 실행. 이 문서나 체크박스만으로 서버 구현이 완료된 것으로 표시하지 않는다.

대괄호 확인란이 남은 방침을 정식 시행본으로 표시하지 않는다. 법정 보존·파기·권리보장에 대한 본문은 운영 기준이며, 현재 서버에 모든 자동 파기·탈퇴·권리 요청 흐름이 구현됐다는 뜻이 아니다. 검토 후 실제 운영에 맞게 본문과 구현을 함께 확정해야 한다.

## 검증

실제 `terms.ts`를 Node에서 실행하여 서비스·정산·개인정보 문서의 파싱과 조 개수(107·39·19), 문서 상태 메타데이터 및 앵커 중복 없음을 확인했다. `/privacy`의 로그인 없이 열리는 라우트, 별칭 이동, 프리페치 등록, 가입 링크 및 포괄 동의 체크 제거를 확인했다. 개인정보 문서 파싱 회귀 테스트를 추가했다. 전체 React 빌드·Vitest는 이 환경의 도구 부재로 실행하지 못했으므로 저장소 CI 확인이 필요하다.
