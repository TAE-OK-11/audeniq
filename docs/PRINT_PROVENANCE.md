# 출력물 식별 (문서 식별코드·원본 검증코드)

인쇄하거나 PDF로 저장할 때 모든 쪽 위·아래에 아래 표식을 찍는다. 대상 문서는 약관, 배급 신청서, 계약서, 권리 서류, 서명 요청 문서, 스태프 심사 기록이다.

- 서버: `crates/core/src/print_stamp.rs`
- 화면: `web/*/src/lib/printStamp.tsx`

```
AUDENIQ · 서린 배급 계약서                              문서 식별코드 AQ-AGR-7F3KQ2M9XA
 (본문)
원본 검증코드 K7Q2M-9XAB3-HT4PZ-8WD1C · 출력 2026.10.12 15:41:09 KST · 출력자 j***@g****.com   진위 확인 studio.audeniq.com/verify
```

## 코드의 의미

| | 문서 식별코드 | 원본 검증코드 |
|---|---|---|
| 의미 | 어떤 문서·어느 내용(판)인지 | 이 출력 한 번 |
| 같은 문서를 다시 출력하면 | 같다(내용이 바뀌면 달라짐) | 매번 새로 발급 |
| 저장 | 평문 | SHA-256 해시만 (원문은 종이에만) |
| 형식 | `AQ-종류-10자` (TRM 약관, STL 정산 약관, PRV 개인정보, APP 신청서, AGR 계약서, RTS 권리 서류, SGN 서명 문서, SUB 심사 기록) | 20자(100비트), 헷갈리는 글자(I·L·O·U) 없음. 소문자·대시 없이 입력해도 된다. |

## 남기는 기록 (`operations.print_stamps`, 수정·삭제 불가)

- **누가:** 계정, 스태프(심사 기록), 또는 서명 링크 수신자(계정 없음). 서명 링크 토큰은 남기지 않고 서명 요청 id만 남긴다.
- **언제:** 출력 시각.
- **어느 기기:** 로그인 세션 id와 브라우저가 처음 출력할 때 만든 기기 id(`localStorage aq.device`).
- **어디서:** IP와 브라우저 정보. 개인정보 키링으로 봉인한다.
- **무엇을:** 문서 참조(약관 판, 발매·문서·서명 요청 id), 화면에 보인 본문의 SHA-256.

**권한:** 서버가 문서를 볼 권한을 확인한 뒤에 발급한다. 신청서·계약서는 그 작업 공간의 구성원만, 서명 문서는 링크 소유자만, 심사 기록은 스태프만 발급받을 수 있다. 약관은 누구나 출력할 수 있다.

## 확인

- **누구나 (`/verify`):** 종이의 원본 검증코드를 입력하면 진위와 요약(문서, 문서 식별코드, 출력 시각, 가린 출력자, 내용 해시)이 나온다. IP·기기 정보는 보이지 않는다. IP당 15분에 30번까지 확인할 수 있다.
- **스태프 (관리 화면 > 출력물 확인):** 전체 기록을 본다. 실명 출력자, 세션·기기 id, IP·브라우저, 같은 문서의 출력 횟수가 나온다. 조회 자체도 스태프 접근 기록에 남는다.

## 브라우저 머리말·꼬리말

- **기본 머리말 제거:** 인쇄 CSS에서 `@page` 여백을 0으로 두면 브라우저가 넣던 시각·URL 머리말·꼬리말이 빠진다.
- **표식 위치(브라우저마다 다름):** 표식은 앱 레이아웃 밖, `body` 바로 아래에 찍힌다.
  - **Chrome·Edge·Firefox(PC·Android):** `position: fixed`라서 모든 쪽 위·아래에 반복된다. 본문 여백은 `box-decoration-break: clone`으로 쪽마다 다시 둔다.
  - **Safari와 iPhone·iPad의 모든 브라우저(WebKit):** WebKit은 fixed 요소를 화면 기준으로 한 번만 찍는다. 그대로 두면 꼬리말이 첫 쪽 중간에 본문과 겹친다. 그래서 머리말은 문서 맨 앞, 꼬리말은 문서 맨 끝에 흐름대로 두고 쪽 여백은 `@page`로 준다.
- **워터마크:** 출력자와 원본 검증코드를 문서 전체를 덮는 반복 배경으로 찍는다. 어느 브라우저에서든 모든 쪽에 남는다.
- **버튼 없이 인쇄한 경우:** 브라우저 메뉴(Ctrl+P)로 바로 인쇄하면 코드 대신 "검증코드 없는 출력물" 경고가 찍힌다.
- **발급 실패:** 서버에서 코드를 받지 못하면(오프라인·체험 모드) "원본으로 확인되지 않는 출력물"이라고 찍힌다.
